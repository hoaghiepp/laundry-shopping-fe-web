# Factory Components

Reusable components for the factory app interface.

## Components

### StatusBadge
Colored badge for displaying status (red, yellow, green, blue, gray).

### SearchBarWithScan
Search input with integrated scan button.

### ItemCard
Card component for displaying laundry items with status, progress, and actions.

### FilterButton
Tab filter button with active/inactive states.

### FactoryHeader
Top header with factory name, section, alerts, and profile.

### FactoryBottomNav
Bottom navigation with 5 tabs including center floating scan button.
